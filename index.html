Projects

Resilient readmission prediction with Apache Spark

Big Data Analytics, Spring 2026

A distributed pipeline that corrupts 28% of 101,766 hospital records, recovers 89.97% of them, and predicts 30-day readmission.

  • PySpark
  • Spark MLlib
  • HDFS

Key features

  • Four simulated data attacks and a cleaning protocol that recovers from them
  • Five engineered clinical features
  • Class weighting for a 6.49 : 1 imbalance
  • Logistic Regression, Decision Tree and Random Forest
  • 4× the data with only 26% more training time

Hospital readmission prediction

Machine Learning, Spring 2026

Seven classifiers compared on noisy patient records to predict which diabetic patients return to hospital.

  • scikit-learn
  • Pandas
  • Streamlit

Key features

  • 69,970 patient records with 10% injected label noise
  • Feature selection, PCA and GridSearchCV
  • Balanced class weights for the minority class
  • Logistic Regression chosen: AUC 0.622, recall 0.53
  • Interactive Streamlit app
Live demo GitHub

Clinical Outcome Prediction from Noisy Medical Records

Data Sciences, Spring 2026

A full data science pipeline and web app that predicts readmission risk for diabetic patients.

  • scikit-learn
  • Pandas
  • Streamlit

Key features

  • Seven-step cleaning, with 900+ diagnosis codes grouped into 7 categories
  • Random Forest feature ranking, then scaling and PCA
  • Logistic Regression, Decision Tree and Random Forest compared
  • Tested with 10% label noise and 5-fold cross-validation
  • Streamlit app with real-time readmission risk
Live demo GitHub
